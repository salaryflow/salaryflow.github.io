개인정보처리방침

최종 수정일: 2026-11-08

Salary Flow는 계정이나 로그인 없이 브라우저에서만 동작하는 무료 급여 추정 도구입니다. 이 문서는 어떤 정보가 어디에 저장되고, 어떤 외부 서비스와 통신하는지 설명합니다.

1. 입력한 급여 정보

연봉, 보너스, 근무 일정, 세금 설정 등 입력한 값은 사용 중인 브라우저의 localStorage에만 저장됩니다. Salary Flow 운영자는 이 값을 수집하거나 서버로 전송하지 않습니다.

  • 저장 항목: 직장별 설정, 세금 옵션, 언어, 표시 통화, 환율 캐시, 기준 데이터 캐시
  • 삭제 방법: 페이지 하단의 모든 데이터 초기화 버튼, 또는 브라우저의 사이트 데이터 삭제
  • 다른 기기나 브라우저와 동기화되지 않습니다.

2. 외부 서비스와의 통신

페이지를 표시하고 계산하기 위해 아래 서비스에 요청을 보냅니다. 이 요청에는 급여 입력값이 포함되지 않지만, 각 서비스는 일반적인 웹 요청처럼 IP 주소, 브라우저 정보 등을 기록할 수 있습니다.

  • GitHub Pages: 사이트 호스팅. GitHub 개인정보 처리방침
  • GitHub API: 세금 기준 데이터의 자동 검사 상태 표시
  • Frankfurter (api.frankfurter.dev): 표시 통화 환율 조회. 요청에는 통화 코드만 포함됩니다.
  • 오프라인 캐시: 앱 설치와 오프라인 사용을 위해 페이지, 아이콘, 기준 데이터가 브라우저의 Cache Storage에 저장됩니다. 급여 입력값은 포함되지 않습니다.

3. 광고

Salary Flow는 운영비 마련을 위해 Google AdSense 광고를 게재할 수 있습니다. 광고가 활성화되면 Google 및 제3자 광고 업체가 쿠키 등을 사용해 이 사이트와 다른 사이트 방문 기록을 바탕으로 광고를 표시할 수 있습니다.

  • Google의 데이터 사용 방식: Google 파트너 사이트 데이터 사용
  • 맞춤 광고 해제: Google 광고 설정 또는 aboutads.info
  • 광고 스크립트는 Salary Flow가 아닌 Google이 제공하며, 운영자는 광고를 위해 급여 입력값을 Google에 전달하지 않습니다.

4. 쿠키

Salary Flow 자체는 쿠키를 설정하지 않습니다. 광고가 활성화된 경우 Google이 광고 쿠키를 설정할 수 있습니다.

5. 아동

이 서비스는 13세 미만 아동을 대상으로 하지 않습니다.

6. 변경 및 문의

이 방침이 바뀌면 이 페이지의 수정일을 갱신합니다. 문의는 GitHub Issues로 남겨 주세요.

Privacy Policy

Last updated: 2026-11-08

Salary Flow is a free salary estimator that runs entirely in your browser, with no account or sign-in. This page explains what is stored, where, and which external services the page contacts.

1. Salary information you enter

Salary, bonus, schedule and tax settings are stored only in your browser's localStorage. The Salary Flow operator does not collect them or send them to any server.

  • Stored items: job settings, tax options, language, display currency, cached exchange rates and reference data
  • To delete: use Reset all data at the bottom of the page, or clear site data in your browser
  • Nothing is synced to other devices or browsers.

2. External services

The page sends requests to the services below. These requests do not include your salary inputs, but each service may log standard request data such as IP address and browser details.

  • GitHub Pages: site hosting. GitHub Privacy Statement
  • GitHub API: status of automated tax-data checks
  • Frankfurter (api.frankfurter.dev): exchange rates for the display currency. Requests include only the currency code.
  • Offline cache: pages, icons and reference data are stored in the browser's Cache Storage so the app can be installed and used offline. Salary inputs are not included.

3. Advertising

Salary Flow may show Google AdSense ads to cover running costs. When ads are enabled, Google and third-party vendors may use cookies to serve ads based on your visits to this and other websites.

  • How Google uses data: How Google uses information from sites that use its services
  • Opt out of personalized ads: Google Ads Settings or aboutads.info
  • The ad script is provided by Google, not Salary Flow. The operator does not pass your salary inputs to Google.

4. Cookies

Salary Flow itself does not set cookies. When ads are enabled, Google may set advertising cookies.

5. Children

This service is not directed at children under 13.

6. Changes and contact

If this policy changes, the date above will be updated. For questions, open an issue on GitHub Issues.
